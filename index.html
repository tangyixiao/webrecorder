WEB ARCHIVE MIRROR / SOURCE PROJECT

让网页，
留下可追溯的副本。

基于 Webrecorder 工具链的网页档案镜像模板，用于保留归档站点的链接结构。

JavaScriptPUBLIC REPOSITORYREAD THE SOURCE

  • WACZ 网页归档

    先使用 Browsertrix 或 ArchiveWeb.page 获得网页档案。

  • 镜像站点链接结构

    模板用于保留归档站点原有的链接关系。

  • GitHub Pages 部署说明

    源码 README 描述 WACZ 配置与 Pages 部署步骤。

这是单域名镜像 starter，须自行提供 WACZ 并遵循 README 配置；介绍页不声称已镜像任何站点。
